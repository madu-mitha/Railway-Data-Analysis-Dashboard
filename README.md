# Railway Data Analysis Dashboard

## 📊 Project Overview

An interactive Railway Data Analysis Dashboard created using Microsoft Excel to analyze railway transactions, revenue, journey status, ticket types, payment methods, railcards, and routes.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard
- Data Analysis
- VBA & Macros

## 📈 Dashboard Features

- Total Revenue and Transaction KPIs
- On-Time, Delayed and Cancelled Journey Analysis
- Refund Analysis
- Average Ticket Price
- Revenue by Purchase Type
- Revenue by Payment Method
- Revenue by Ticket Type
- Revenue by Ticket Class
- Transactions by Railcard
- Journey Status & Disturbance Reasons
- Transactions by Purchase Type
- Top 10 Routes
- Interactive Slicers

## ⚙️ VBA Automation

The dashboard includes VBA macros for:

- Refreshing the dashboard
- Resetting all filters
- Exporting the dashboard to PDF

## 💡 Key Business Insights
- Total transactions: 31,653
- Total revenue: GBP 741,921
- On-time journeys: 27,481
- Delayed journeys: 2,292
- Cancelled journeys: 1,880
- Refunds: 1,118
- Average ticket price: GBP 23.44
- Credit Card generated the highest revenue among payment methods.
- Standard Class generated higher revenue than First Class.
- Manchester-related routes appeared among the highest-volume routes.

## 🎯 Project Objective

The objective of this project is to transform railway transaction data into an interactive dashboard that helps identify revenue patterns, journey performance, customer behavior, and operational trends.
